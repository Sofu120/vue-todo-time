# Vue Todo List with Time

結合一天的時間軸的 To-do list 應用，使用 Vue 3 + TypeScript + Vuex 開發。

## 功能特點

- 新增、刪除和標記完成待辦事項
- 可以幫每個待辦事項設置開始和結束時間
- 時間軸顯示所有待辦事項
- 按時間順序自動排序
- 視覺化顯示

## 技術

- Vue 3
- TypeScript
- Vuex 4
- Vite

## 安裝和運行

1. 下載：
git clone https://github.com/Sofu120/vue-todo-time.git

2. 安裝
cd vue-todo-time
npm install

3. 運行
npm run dev

4. 瀏覽器運行，在網頁上輸入
http://localhost:5173
